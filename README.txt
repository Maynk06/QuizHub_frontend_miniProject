QUIZORA - FRONTEND QUIZ APP
===========================

HOW TO OPEN
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open the app in a browser.

SUBJECTS
- Frontend Engineering: HTML, CSS and JavaScript
- Advanced Java: Swing, AWT and JDBC
- Computer Networks
- Aptitude
- Cloud Computing

Each starter quiz contains 10 questions.
